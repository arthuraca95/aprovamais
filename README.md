# AprovaMais

## Sobre o projeto

O AprovaMais é um projeto social que busca facilitar o acesso a materiais gratuitos para pessoas que estudam para concursos públicos.

## Problema social

Muitas pessoas não têm condições de pagar cursos preparatórios e nem sabem onde encontrar materiais gratuitos.

## Objetivo

Reunir em um único lugar editais, apostilas, videoaulas e cronogramas de estudo gratuitos.

## Público-alvo

Estudantes e candidatos a concursos públicos.

## Tecnologias

- HTML
- GitHub

## Status

Projeto em desenvolvimento.
